# Changelog

## v2.3.10 — 2026-11-20

- Free and open-source WordPress SEO & GEO plugin for Chinese businesses, site builders, and multilingual websites.
- Includes metadata management, XML sitemaps, Schema.org, redirects, crawl diagnostics, Baidu-related settings, GEO content tools, and hreflang translation groups.
- GitHub edition renders a visible, standalone Aikeyboost credit on public pages without replacing theme copyrights or legal notices; no administration toggle is provided.
- Database schema version 17; no premium extension is bundled.
- PHP syntax checks, dedicated footer regression assertions, and the release ZIP checksum and structure have passed in GitHub CI (PHP 8.0, 8.2, and 8.3).
- Full live WordPress integration testing remains outstanding.
